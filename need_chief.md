# Исходные данные для реализации

Принято: единая навигация по всем предусмотренным системам, местные оси датчиков, географический выход,
широкая диаграмма радиовысотомера 120°, ограничение применения 2000 м, восстановление по рельефу,
сторож на коротком, среднем и длинном интервалах с подбором длительностей.

Для численной реализации ещё нужны фактический перечень приборов, описания их выходов и погрешностей,
время измерений и задержки, требования потребителя к точности и времени предупреждения, модель отказов.
Матрица высот находится на рабочем компьютере пользователя; для разработки разрешён открытый набор.
Получен один участок Copernicus GLO-30 N36/W113 с высотами EGM2008; его параметры не задают свойства бортовой карты.

Основное изложение: docs/ekf_theory.md.
