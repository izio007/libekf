# libekf

Единая навигационная оценка по доступным системам, восстановление положения по рельефу и отдельная проверка достоверности.

**Описание для аналитика:** [идея, состав систем и рисунок](docs/ekf_theory.md).

Реализован общий путь подготовленных измерений: физическая модель, проверка единиц, времени, погрешностей и исправности, преобразование осей, инерциальное продолжение и поправка оценки. Поддерживаются измерения внутри инерциального интервала и пересчёт явно сохранённой истории при запоздании. Выход — широта, долгота и эллипсоидальная высота с оценкой погрешности и результатами назначенных проверок.

Это ещё не завершённая бортовая система. Не закончены автоматическое ведение истории и общих ошибок опор, полный поиск положения по рельефу, независимые проверочные каналы с изоляцией отказов, обработка исходных кадров и радиосигналов. Численные проверки подготовленных наблюдений не подтверждают готовность этих частей.
Соответствие авиационным требованиям и сертификация не заявлены.

## Проверки

В MATLAB из корня проекта:

```matlab
addpath('matlab');
status = run_tests;
```

Все проверки находятся в одном файле matlab/run_tests.m. Девятнадцать групп проверяют физический смысл показаний, общую поправку и инерциальное продолжение, происхождение данных, сохранение результата при смене координат, численную устойчивость, широкую диаграмму радиовысотомера, сравнение последовательностей и три интервала контроля. Сквозная проверка охватывает все 30 проверяемых обозначений моделей наблюдений; часть обозначений относится к одинаковой физической модели и не означает независимых приборов.
Результаты возвращаются по каждому требованию. Настройки JSON и отдельные файлы отчётов для запуска не нужны.

## Материалы

- docs/ — принятые решения, теория и поясняющий рисунок.
- docs-src/ — отобранные основополагающие оригиналы и один открытый участок рельефа.
- matlab/function/ — вычислительные функции; matlab/run_tests.m — проверки поведения.
- Principes/ — применимая методика работы по образцу libtr.
- need_*.md — актуальные незавершённые вопросы.
- runtime/ — история, служебные скрипты и промежуточные материалы; в Git не входит.

libekf — самостоятельный проект. Требования и результаты libtr автоматически не наследуются.
