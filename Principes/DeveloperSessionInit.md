# Начало работы в libekf

1. Прочитай задачу пользователя и [.clinerules](../.clinerules).
2. Проверь состояние Git и только относящиеся к задаче файлы.
3. Для продолжения темы используй [манифест](../docs/ekf_theory.md), соответствующий docs/*_theory.md
   и нужные записи need_work.md, need_chief.md, need_correct.md. Весь архив перечитывать не требуется.
4. Выполни минимальную необходимую правку, проверь затронутый результат, сообщи факт и границы проверки.

Методика по теме: V_PROCESS_CONFIGURATOR.md — состав содержания; PaeroPrincipe.md — математика;
LOGIC_DESIGN_STANDARD.md — логика с состоянием; VPrincipe.md — достаточная проверка;
PlainTextPrincipe.md — Markdown и преобразование представлений.

Память обновляется по смыслу изменения в основном предметном документе, без обязательного отчёта каждого шага.
История ideas/ и proposals/ не запускает задачи автоматически. Старые предметные материалы libtr — справочные.
Оригиналы из интернета — ../docs-src/; нормативный обзор и реестр — ../docs/.
Не создавать карточки, дополнительные согласования и проверки регламентов.
Сохранять независимые математические тесты и чужие изменения. Невыполненный запуск не считать успешным.
