# libekf

Единая навигационная оценка по доступным системам, восстановление положения по рельефу и отдельная проверка достоверности.

**Описание для аналитика:** [идея, состав систем и рисунок](docs/ekf_theory.md).

Сейчас реализованы физические модели наблюдений, преобразования координат, инерциальное продолжение на коротком шаге, шаг поправки общей оценки Калманом и выход широты, долготы и эллипсоидальной высоты.
Полный фильтр движения, привязка потерянного положения по последовательности измерений и сторож на трёх интервалах ещё разрабатываются.
Соответствие авиационным требованиям и сертификация не заявлены.

## Проверки

В MATLAB из корня проекта:

```matlab
addpath('matlab');
status = run_tests;
```

Все проверки находятся в одном файле matlab/run_tests.m. Десять групп проверяют физический смысл показаний, общую поправку и инерциальное продолжение, происхождение данных, сохранение результата при смене координат, численную устойчивость, широкую диаграмму радиовысотомера, сравнение последовательностей и три интервала контроля. Сквозная проверка охватывает все 17 поддерживаемых обозначений моделей наблюдений; часть обозначений относится к одинаковой физической модели и не означает независимых приборов.
Результаты возвращаются по каждому требованию. Настройки JSON и отдельные файлы отчётов для запуска не нужны.

## Материалы

- docs/ — принятые решения, теория и поясняющий рисунок.
- docs-src/ — отобранные основополагающие оригиналы и один открытый участок рельефа.
- matlab/function/ — вычислительные функции; matlab/run_tests.m — проверки поведения.
- Principes/ — применимая методика работы по образцу libtr.
- need_*.md — актуальные незавершённые вопросы.
- runtime/ — история, служебные скрипты и промежуточные материалы; в Git не входит.

libekf — самостоятельный проект. Требования и результаты libtr автоматически не наследуются.
